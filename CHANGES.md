 - First public version of the PEVO Pilot website at
   https://blappm.github.io/pevo-web/, published automatically on every
   change to the `main` branch.

 - Page texts can now be edited directly on GitHub in the files under
   `content/home/`, one file per section; navigation and footer are in
   `hugo.toml`. See "Inhalte bearbeiten" in the README.

 - On phones the page could be dragged sideways by a few millimetres,
   showing an empty strip on the right; it now fits the screen width.

 - The "Community Forum" button at the bottom of the page led to the
   GitHub start page; it is now labelled "Fragen & Ideen auf GitHub" and
   opens the PEVO issue tracker.

 - The website is now at https://pevo.io (also www.pevo.io); the old
   address https://blappm.github.io/pevo-web/ forwards there.
